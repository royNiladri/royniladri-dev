1Three directions: home, work history, mobile
Who it's for
Hiring managers, tech leads and HR who already have the resume. The home page reads in about a minute; detail is there for anyone who wants it.
Work history
Three levels of detail: role summaries and highlight titles, then full project write-ups, then a page per employer. You can filter by skill, switch between highlights and everything, and each project keeps its skill and tech markers.
Static by design
All content lives in one JSON file (employers → roles → projects), so a new employer is one new entry. Builds with Astro or plain HTML on GitHub Pages. No API or database.
1aEditorial: Newsreader serif, lots of white space, timeline with a year gutter and roles that expand in place
